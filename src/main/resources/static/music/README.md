# 音乐文件（兜底位置）

**日常加歌不要放这里。** 放项目根目录的 `music/` 去 ——
那里是外挂目录，加歌不用重新打包 jar，也不用重启。

详细的加歌步骤看 → [`/music/README.md`](../../../../../../music/README.md)
（也就是项目根目录下的 `music/README.md`）

---

## 这个目录是干什么的

后端把 `/music/**` 交给了外挂目录，查找顺序是：

```
1. <项目根>/music/            ← 外挂，优先
2. classpath:/static/music/   ← 就是这个目录，兜底
```

所以这里平时**应该是空的**。它的意义只有两个：

1. **关掉外挂时还能用**：配置里写 `app.static.music-dir: ""`，
   那就完全回到"音乐打进 jar"的老模式，文件放这里
2. **有个稳定的兜底位置**：外挂目录配错、路径失效时，不至于整个 404

## 放这里会怎样

会生效，但优先级比外挂目录**低** —— 同名文件永远用外挂目录的那份。

这也是为什么**不建议**放这里：一旦这里和外挂目录都有同名文件，
改了外挂那份却没反应，很难查。
（`data-test/music-url-test.ps1` 里专门有一项检查这个坑。）
